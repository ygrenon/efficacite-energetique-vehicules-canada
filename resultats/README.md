# Résultats du projet SCI 1402

Ce dossier contient les tableaux de résultats produits par le troisième notebook (`03_analyses_complementaires.ipynb`), lors de la manipulation M030.

## Description des fichiers

- **comparaison_modeles.csv** : comparaison des performances des modèles prédictifs évalués.
- **performances_chronologiques.csv** : résultats des évaluations chronologiques du modèle Random Forest.
- **distribution_erreurs.csv** : répartition des erreurs absolues de prédiction.
- **importance_variables.csv** : importance des variables explicatives évaluée par permutation.

Ces tableaux permettent de consulter les résultats numériques et facilitent leur réutilisation pour la présentation et le rapport final du projet.

**Source des données :** Ressources naturelles Canada (RNCan), années modèles 2015 à 2024.
